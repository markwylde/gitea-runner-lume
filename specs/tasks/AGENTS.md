# AGENTS — implementation tasks

Task files are ordered delivery plans, not product contracts.

- Tick a checklist item only after its implementation and proportionate
  verification are complete.
- Keep dependencies explicit and do not begin a dependent slice while an
  unresolved proof gate could invalidate it.
- Update the governing feature first if implementation reveals a behavioural
  change.
- Move a fully completed task to `../tasks_completed/`.
